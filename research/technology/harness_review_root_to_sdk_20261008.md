# 独立レビュー：開発用SDKの保護境界

レビュー日：2026-10-08。対象は `harness_sdk_security_20261008.md` と固定原本。別担当が作成した稿を、親担当が原本と照合した。製品の実行環境全体の試験や検出精度の評価ではない。

| 検証した主張 | 原本の確認 | 判定 |
|---|---|---|
| Agents SDKの入力検査は並行が既定 | `docs/guardrails.md` の実行方式と `run_internal/guardrails.py` の起動・例外処理 | 正確。送信前の阻止には逐次実行が必要 |
| 出力の拒否と検査例外では保存が異なる | 同文書54–58行、`blocked_output.py`。拒否時の関数引数保持も文書に明示 | 正確。拒否結果の置換を全保存経路の削除と説明していない |
| 独自の追跡処理器の追加だけでは既定配信を置換しない | `tracing/setup.py` 55–59行で既定を登録、`provider.py` 117行以降で各処理器の例外を個別捕捉 | 正確。原文を追跡へ入れる前の方針が必要 |
| 暗号化Sessionは読出し時に平文へ戻る | `encrypt_session.py` 312行以降の暗号包みと読出し。期限切れの回収と非表示を区別 | 正確。暗号文推論・物理削除の保証にしていない |
| Unix-localのLinuxはOS隔離なし、macOSも通信は隔離なし | `unix_local.py` の267行と1520行以降に明記、既定の環境変数継承も確認 | 正確。Docker等への一般化なし |
| LangChain最新PIIは128文字の断片間検査を持つ | `pii.py` 38–112行。状態表示のコピーと元のgraph状態を区別する説明も原本に一致 | 正確。公開イベントの伏字を実引数の変更と説明していない |
| LangGraph暗号serializerは平文fallbackを持つ | `encrypted.py` の型名による分岐 | 正確。保存前の全項目暗号化を主張していない |
| SQLite metadataは別のJSONで保存 | SQLite保存器431–447行 | 正確。他の保存器にも同一と一般化していない |
| Deep Agentsファイル権限は最初の一致、未一致許可 | `middleware/filesystem.py` 402–412行 | 正確。OSの強制制限と区別 |
| LocalShellの環境変数は既定非継承だがshell隔離なし | `local_shell.py` 110–140行 | 正確。仮想rootはshellを制限しないとの注記に一致 |

重要な修正要求は見つからなかった。全種類の道具・言語・SDK実装を実測済みと扱わず、Python固定版と公式仕様の範囲を保つことを確認した。最新実装に合わせたストリーム変換・ローカルMCPの検査対応・保存時暗号化を含めることで、旧仕様の一括判断を避けている。

原本の固定URLと保存ハッシュは [SDK資料台帳](harness_sdk_sources_20261008.json) を参照。
