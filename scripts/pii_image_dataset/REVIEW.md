# LIGHTの生成・検証・独立レビュー記録

## 判定

ローカル資料は生成・検証を通過した。Astraによる独立レビューの指摘を修正し、再現攻撃の拒否も再確認した。ただし、Google Sheetsの実環境作成・権限試験3条件は未実施であり、LIGHT全体の完成とは扱わない。DLP製品での精度測定も未実施。

ローカル成果物は`artifacts/pii-light`、検証記録は検査範囲外の`artifacts/pii-light-checks`へ保存する。再実行方法と作成過程は[説明書](README.md)を参照。

## 独立レビューの指摘と修正

| 指摘 | 修正・再検証 |
|---|---|
| 複数ページの正解が1回分しかない | PDFのページ・TIFFのフレームごとに出現を記録。PDFは全ページの実出現集合と比較し、TIFFは各フレームの対象集合を照合 |
| 結合セル以外にも答えが残る | 結合セル条件では通常セルに本文を書かない |
| TXTをDOCXと偽っても通る | 本文抽出前に必須部品・文書種別を含む実形式検証を追加 |
| 陰性本文の追記を見逃す | 信頼する正解側の復元内容指紋に加え、原稿・固定ひな形と本文・格納面を比較 |
| PDFに追加した画像が指紋に反映されない | 画像等を含む復号後の構造も指紋化。PDF/Officeの画像・添付・埋込み個数を条件別に確認 |
| TIFF・ZIP内画像PDFが媒体検査から漏れる | 入口条件に追加し、TIFFは全フレーム照合 |
| 実在しない空ディレクトリが通る | 実在、配下集合、内容の陽性判定を照合 |
| 別人に同じ読み仮名を付ける | 元人物に対応する読みを明示 |
| Sheetsの未確認出力が入力へ混ざる | 正解保存側の保留領域へ隔離 |
| 権限付与直後に取消される | 付与、別主体の読取、取消、拒否確認へ段階化 |
| API無効の403も取消成功になる | エラー原因を分類し、設定障害・原因不明を成功にしない。所有者でも資料の実在を再確認 |
| Word削除履歴の文字を比較しない | `delText`等も原稿照合へ追加 |
| JSON項目名の混入を見逃す | JSON/JSONLは項目名を含む既知の構造と比較 |

Astraは隔離した複製で攻撃例を再現し、修正後の回帰16試験を独立実行した。直近の確認範囲に未解決指摘はないとの判定。これは未試験の全経路の完全性を保証するものではない。

氏名だけ、メールだけ、番号だけの陽性を22例設け、氏名・メール双方を含む基準陽性を120件から98件へ減らした。予約などの文書間照合は観測できる事実と人物への帰属を分け、結合可否ごとの正解を`conditional_expectations.json`へ記録した。Astraも6構成の参照先・対象文字位置・結合可否を独立確認した。

## 元データと限界

外部の人物データセットや実在の証明書は使用せず、独自の架空例を使う。生成AIへの問い合わせはない。番号の未割当・未発行、法的分類の確定、証明書の実物配置・真贋は保証しない。画像劣化は追加していない。

原稿の独立比較は文字・構造化資料、PDF、陰性のXMLベースOffice、陰性書庫・メールの内部を対象とする。すべてのバイナリ形式・属性・画像文字について意味的な陰性を証明するものではない。指紋も正解自体の改ざん防止署名ではなく、信頼する正解と現物の差を検出する仕組みである。

元文書のひな形・属性文には反復がある。派生と999陰性コピーを独立した精度標本として数えない。LIGHTは22項目と形式・条件への対応確認に使えるが、実務全体の精度や低い誤警告率の数値保証には別の独立資料が必要。

`drive_upload`だけを検査し、正解・鍵・生成設定・保留したクラウド出力を入力へ混ぜない。読取不能は陰性や検出漏れから分離し、検出結果を種類・人物への関係・出現位置と製品の出力粒度に合わせて採点する。

## クラウド作成処理の再開対応

Google Sheetsは1資料ずつの作成、保存した報告からの再開、元資料指紋の照合、同時実行抑止を追加した。模擬サービスで28資料168出力を確認し、通信失敗、HTTP503、保存後の応答喪失、初回報告更新失敗からの再開も検証する。実環境でのGoogle側の挙動は未確認。最終照合や出力物の正解確認を省略する仕組みではない。


再開処理の独立レビューでは、HTTP503を再試行しない点、保存後の応答喪失による出力重複、初期報告更新失敗後の再開不能を指摘された。失敗出力の既定再試行、保存先・名前による既存出力の回収、有効な初期報告と再開参照の保存順を修正した。Astraは修正後の故障試験を独立実行し、初回更新失敗後も同じ入口から復帰しフォルダーが増えず、28資料・168出力、失敗0・未試行0となることを確認した。今回の模擬確認範囲に未解決指摘はない。Google実環境の確認とは区別する。
