    AI Gateway

    The Netskope AI Gateway is a software layer designed to act as a gateway to intercept and secure traffic between AI agents and AI models (LLMs).

    In your own deployments (VPC or on-prem), AI Gateway enables applications to access LLMs securely with capabilities such as authentication, rate limiting, prompt/response filtering, monitoring, logging, content moderation, and DLP. 

    Benefits

    AI Gateway provides the following benefits:

    • Provides a single API for interacting with various AI models.
    • Data Leakage Prevention (DLP): Monitors and blocks sensitive organizational data from leaving the network.
    • Content Moderation: Provides AI guardrail protection by preventing attacks such as prompt injection and inappropriate content.
    • Authentication: Manages secure access through token-based authentication.
    • Rate Limiting: Controls the volume of requests to prevent abuse and manage traffic.
    • Monitoring & Compliance: Tracks usage and ensures interactions meet corporate standards.
