            <h2>Abstract</h2>
            <p>The memorization of sensitive and personally identifiable information (PII) by large language models (LLMs) poses growing privacy risks as models scale and are increasingly deployed in real-world applications. Existing efforts to study sensitive and PII data memorization and develop mitigation strategies are hampered by the absence of comprehensive, realistic, and ethically sourced datasets reflecting the diversity of sensitive information found on the web. We introduce <b>PANORAMA: Profile-based Assemblage for Naturalistic Online Representation and Attribute Memorization Analysis</b>, a large-scale synthetic corpus of <b>384,789 samples derived from 9674 synthetic profiles</b> designed to closely emulate the distribution, variety, and context of PII and sensitive data as it naturally occurs in online environments.</p>
            <p>Our data generation pipeline begins with the construction of internally consistent, multi-attribute human profiles using constrained selection to <b>reflect real-world demographics</b> such as education, health attributes, financial status, etc. Using a combination of zero-shot prompting and OpenAI o3-mini, we generate diverse content types—including wiki-style articles, social media posts, forum discussions, online reviews, comments, and marketplace listings—each embedding realistic, contextually appropriate PII and other sensitive information.</p>
            <p>We validate the utility of PANORAMA by fine-tuning Mistral-7B model on 1x, 5x, 10x and 25x data replication rates with a subset of data and measure PII memorization rates - revealing not only consistent increases with repetition but also variation across content types, highlighting PANORAMA’s ability to model how <b>memorization risks differ by context</b>. Our dataset and code are publicly available, providing a much-needed resource for privacy risk assessment, model auditing, and the development of privacy-preserving LLMs.</p>
        </section>

        <section id="dataset-generation">
            <h2>Dataset Generation Pipeline</h2>
            <div class="image-container">
                <img src="assets/images/datageneration_pipeline_overview.png" alt="Dataset Generation Pipeline">
                <p class="caption">Overview of the PANORAMA dataset generation pipeline.</p>
            </div>
            <p>Our data generation pipeline consists of three main steps. First, we generate synthetic profiles that include all required target attributes. Next, these profiles are used to construct detailed biographical narratives, which serve as the basis for content generation. Finally, we leverage these biographies to produce diverse content types in which sensitive attributes are contextually embedded.</p>

      document.addEventListener('DOMContentLoaded', function() {
        const navList = document.getElementById('tab-nav-list');
        const sections = [
          'home',
          'abstract',
          'compare-datasets',
          'dataset-generation',
          'content-targeting',
          'citation'
        ];
        let links = Array.from(navList.querySelectorAll('.tab-link'));
        const panoramaLi = document.createElement('li');
        const panoramaA = document.createElement('a');
        panoramaA.href = '#';
        panoramaA.className = 'tab-link panorama-tab';
        panoramaA.textContent = 'PANORAMA';
        panoramaA.setAttribute('data-section', 'home');
        panoramaLi.appendChild(panoramaA);
        function updateLinks() {
          links = Array.from(navList.querySelectorAll('.tab-link'));
        }
        function onScroll() {
          let scrollPos = window.scrollY || window.pageYOffset;
          if (scrollPos > 80) {
            if (!navList.contains(panoramaLi)) {
              navList.insertBefore(panoramaLi, navList.firstChild);
              updateLinks();
            }
          } else {
            if (navList.contains(panoramaLi)) {
              navList.removeChild(panoramaLi);
              updateLinks();
            }
          }
        }
        window.addEventListener('scroll', onScroll);
        onScroll();
        navList.addEventListener('click', function(e) {
          const link = e.target.closest('.tab-link');
          if (!link) return;
          e.preventDefault();
          const section = link.getAttribute('data-section');
          if (section === 'home') {
            window.scrollTo({ top: 0, behavior: 'smooth' });
          } else {
            const sec = document.getElementById(section);
            if (sec) {
              window.scrollTo({ top: sec.offsetTop - 70, behavior: 'smooth' });
            }
          }
        });
      });
