# 調査で使う用語の日本語説明

説明文は日本語とし、製品名・論文の原題・識別子・コードは原表記を保持する。既存調査に残る専門語は以下の意味で読む。

| 表記 | 日本語での意味 |
|---|---|
| AI-native / AI-only company | AIの利用を前提に業務と組織を設計する企業／AIが中心に業務を行う企業 |
| agent / エージェント | 目標に沿って判断し、外部の道具を使って作業するAI |
| loop / ループ | 同じ手順を結果に応じて繰り返すこと。本調査では問い・調査・再質問の反復 |
| task / タスク | 評価や実行の単位となる課題・作業 |
| benchmark / ベンチマーク | 同じ条件で能力を比較する評価課題と採点方式 |
| vendor / ベンダー | 製品やサービスの提供企業 |
| LLM / モデル | 大規模言語モデル／学習した情報から予測・生成する仕組み |
| RAG | 外部の資料を検索し、その根拠を使って回答を生成する方式 |
| GraphRAG / ナレッジグラフ | 実体の関係図を使う検索追加型生成／事実と関係を構造化した図 |
| ontology / オントロジー | 分野の概念、属性、関係を定義した体系 |
| semantic layer / セマンティックレイヤー | 売上などの指標、用語、結合、集計粒度を正式に定義する層 |
| embedding / 埋め込み | 文章などを検索・比較用の数値列へ変換したもの |
| chunk / チャンク | 検索用に分割した文章片 |
| memory / メモリ | AIが後の作業に使う保存情報。業務の正式な状態とは区別する |
| skill / スキル | AIに作業手順・道具・補助資料を追加する拡張単位 |
| prompt injection | 外部の文章などへ不正な指示を混ぜ、AIの動作を変える攻撃 |
| hallucination | 根拠のない事実や誤った内容の生成 |
| provenance / lineage | 出所・生成経緯／資料や版の派生関係 |
| ACL | 対象ごとの閲覧・操作を許す主体の一覧 |
| RBAC / ABAC / ReBAC | 役割／属性／主体と対象の関係に基づくアクセス制御 |
| PDP / PEP | 認可の判断を行う部分／判断を実際に強制する部分 |
| IFC / taint tracking | 情報の流れの制御／情報の信頼性や機密性の印を追跡すること |
| tenant / テナント | 共通基盤を利用する企業・顧客ごとの分離領域 |
| cache / キャッシュ | 以前の結果を一時保存して再利用する仕組み |
| egress / sink | 外部への送信経路／情報の渡し先 |
| sandbox / サンドボックス | 信用できない処理を制限して実行する隔離環境 |
| microVM / container | 小さな仮想機械／OSの機能を使った処理の分離単位 |
| TEE / Confidential Computing | 信頼実行環境／計算中の情報を基盤運営者などから保護する技術 |
| FHE / MPC / DP | 完全準同型暗号／秘密を分けた共同計算／差分プライバシー |
| bi-temporal | 事実が有効だった期間と、それを把握した時点を分ける時間管理 |
| control plane | 実行主体の権限、設定、資源、状態を管理する制御基盤 |
| gateway | 呼び出しを仲介し、認可や記録を行う窓口 |
| harness | AIを動かす手順、道具、状態管理、評価などの周辺実行基盤 |
| trace / span | 一連の処理経路／その中の個々の処理区間 |
| audit log | 認可・参照・操作・変更の根拠を残す監査記録 |
| XAI / explainability | 説明可能AI／判断や処理を利用者へ説明できる性質 |
| interpretability / faithfulness | 内部の動作を解釈できること／説明が実際の処理に忠実なこと |
| HITL / Human on the Loop | 人を判断過程へ入れること／自律処理を人が監督すること |
| gate / guardrail | 実行前の通過条件／危険な動作を制限する仕組み |
| kill switch / rollback | 緊急停止／以前の検証済み状態へ戻すこと |
| idempotency | 同じ依頼を再実行しても作用を重複させない性質 |
| mandate / receipt | 委任・承認の証跡／操作の受領記録。決済完了とは限らない |
| judge / bias | 採点者／評価の偏り |
| pass@k / pass^k | k回のうち一度でも成功する指標／k回全て成功する指標 |
| GA / preview | 一般提供／試験提供。適用条件は製品ごとに確認する |
| OSS / SaaS / SDK / API | 公開ソフトウェア／サービスとして使うソフトウェア／開発用部品／プログラムからの呼び出し口 |
| CS / IR / SLA | 顧客対応／投資家向け情報提供／サービス水準の契約 |
| pricing / outcome-based | 料金設計／成果に基づく方式 |
| misevolution / reward hacking | 自己改善が望まない方向へ進むこと／本来の目的を満たさず評価値だけを高めること |
