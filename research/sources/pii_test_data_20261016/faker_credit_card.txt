<dd><p>Bases: <a class="reference internal" href="baseprovider.html#faker.providers.BaseProvider" title="faker.providers.BaseProvider"><code class="xref py py-class docutils literal notranslate"><span class="pre">BaseProvider</span></code></a></p>
<p>Implement default credit card provider for Faker.</p>
<p>For all methods that take <code class="docutils literal notranslate"><span class="pre">card_type</span></code> as an argument, a random card type
will be used if the supplied value is <code class="docutils literal notranslate"><span class="pre">None</span></code>. The list of valid card types
includes <code class="docutils literal notranslate"><span class="pre">'amex'</span></code>, <code class="docutils literal notranslate"><span class="pre">'diners'</span></code>, <code class="docutils literal notranslate"><span class="pre">'discover'</span></code>, <code class="docutils literal notranslate"><span class="pre">'jcb'</span></code>, <code class="docutils literal notranslate"><span class="pre">'jcb15'</span></code>,
<code class="docutils literal notranslate"><span class="pre">'jcb16'</span></code>, <code class="docutils literal notranslate"><span class="pre">'maestro'</span></code>, <code class="docutils literal notranslate"><span class="pre">'mastercard'</span></code>, <code class="docutils literal notranslate"><span class="pre">'visa'</span></code>, <code class="docutils literal notranslate"><span class="pre">'visa13'</span></code>,
<code class="docutils literal notranslate"><span class="pre">'visa16'</span></code>, and <code class="docutils literal notranslate"><span class="pre">'visa19'</span></code>.</p>
<p>Sources:</p>
<ul class="simple">
<li><p><a class="reference external" href="https://en.wikipedia.org/wiki/Payment_card_number#Issuer_identification_number_.28IIN.29">https://en.wikipedia.org/wiki/Payment_card_number#Issuer_identification_number_.28IIN.29</a></p></li>
<li><p><a class="reference external" href="https://www.regular-expressions.info/creditcard.html">https://www.regular-expressions.info/creditcard.html</a></p></li>
<li><p><a class="reference external" href="https://creditcardjs.com/credit-card-type-detection">https://creditcardjs.com/credit-card-type-detection</a></p></li>
</ul>

<dd><p>Generate a credit card expiry date.</p>
<p>This method uses <a class="reference internal" href="faker.providers.date_time.html#faker.providers.date_time.Provider.date_time_between" title="faker.providers.date_time.Provider.date_time_between"><code class="xref py py-meth docutils literal notranslate"><span class="pre">date_time_between()</span></code></a> under the hood to generate the

here as it would in that method. For the actual formatting of the expiry
date, <a class="reference external" href="https://docs.python.org/3/library/datetime.html#datetime.datetime.strftime" title="(in Python v3.15)"><code class="xref py py-meth docutils literal notranslate"><span class="pre">strftime()</span></code></a> is used and <code class="docutils literal notranslate"><span class="pre">date_format</span></code> is simply passed
